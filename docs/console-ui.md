# Консольный интерфейс Havoc

Главное меню вдохновлено компоновкой игровых консолей: плитки разделов,
кинематографичный фон, крупный заголовок и отдельная кнопка действия.
Это собственное оформление Havoc, без логотипов PlayStation.
Фон `console_background.png` — созданная для проекта AI-иллюстрация.

## Управление

- Первый клик выбирает плитку; клик по выбранной плитке открывает раздел.
- Стрелки влево/вправо выбирают раздел; Enter активирует выбранную кнопку.
- Tab / Shift+Tab переключают фокус между плитками, основной кнопкой,
  языком и специальными возможностями. Это настоящие кнопки Minecraft:
  сохраняются озвучивание, звук нажатия и клавиатурная навигация.
- Аккаунты: добавление ника, выбор, применение и удаление; длинный список
  прокручивается колесом. Закрытие: крестик, Esc или клик за пределами панели.

Общие текстовые кнопки, кнопки-переключатели, использующие стандартную
подложку, и слайдеры Minecraft получили консольное оформление.
Их обработка ввода, подписи, подсказки и озвучивание не заменяются.
Специализированные элементы с собственной отрисовкой (слоты инвентаря,
галочки, серверные строки, ClickGUI модулей) не подменяются этими миксинами.

## Ручная проверка в Minecraft 26.2

1. Проверить меню при GUI Scale 1–4 и Auto, в окне и полноэкранном режиме.
2. Пройти все пять разделов мышью, стрелками и Tab; проверить возврат назад.
3. Открыть языки и специальные возможности.
4. Добавить более пяти аккаунтов, прокрутить, применить и удалить последний.
   Фоновые кнопки не должны нажиматься, пока открыта панель аккаунтов.
5. Проверить настройки графики, звука и управления, выбор мира, серверы
   и меню паузы: наведение, фокус, неактивные кнопки, длинные подписи.
6. Проверить перетаскивание слайдеров и изменение значений клавиатурой.
7. Проверить главное меню со светлой и тёмной темами ClickGUI:
   консольные поверхности должны оставаться читаемыми в обоих случаях.

Успешная сборка не заменяет визуальную проверку и проверку применения
миксинов при запуске игры.

## Библиотека миров и серверов (референс с PS5)

- Горизонтальная лента обложек; выбранная карточка больше соседних.
- Для миров используются штатные `icon.png`, для серверов — favicon.
  При отсутствии серверной иконки показывается тематическая иллюстрация.
- Название, описание и кнопка запуска находятся в нижней левой части.
  Справа на широком окне — дата последней игры или онлайн/пинг.
- Кнопка `•••` открывает **оригинальные кнопки Minecraft**: создание,
  редактирование, удаление, пересоздание мира / прямое подключение,
  добавление, редактирование, удаление и обновление серверов.
- Сохранены подтверждения удаления, проверки версий, резервное копирование,
  поиск миров, LAN-обнаружение и возврат из дочерних экранов.
- Стрелки, колесо, Home/End листают библиотеку; Tab переключает реальные
  элементы интерфейса. Enter на выбранной карточке запускает мир/сервер.
- Сетевые запросы идут вне render thread, только для показанных серверов.
  При закрытии экрана очереди пинга останавливаются, иконки освобождаются.
- Главное меню использует те же пропорции: крупная выбранная обложка и
  блок действия внизу, а не под лентой.

Дополнительная ручная проверка: 0/1/20+ миров и серверов, поиск без
результатов, LAN, недоступный сервер, сервер без иконки, смена размера окна,
возврат из редактирования/подтверждения удаления. Нативное поведение при
отсутствии миров сохранено: Minecraft может сразу открыть создание мира.
