# Console v2 — макет на согласование

**Статус: дизайн-превью, не реализованный игровой экран.**
На этом этапе Java-код и готовый JAR не меняются. Макет не выдаётся
за скриншот Minecraft; на самих изображениях есть соответствующая подпись.

## Что меняется относительно первой реализации

- Обложки 108 px, выбранная — 180 px при размере макета 1920 × 1080.
- Ландшафтные обложки кадрируются, а не сжимаются в квадрат.
- Внутри плиток нет названий: полное название видно рядом с выбранной.
- Аккаунты, настройки и выход — единые тёмные панели с простыми иконками.
  Розовая иллюстрация больше не используется для служебных разделов.
- Вместо огромного слогана — компактные логотип-текст MINECRAFT и название
  раздела. Иллюстрация справа остаётся главным визуальным элементом.
- Кнопки спокойные, овальные, без постоянной светящейся обводки.
- На главном меню появляется «•••» для дополнительных действий. Это пока
  предложение дизайна, а не утверждение о наличии такой кнопки в JAR.

После согласования: перенести композицию в главный экран и обе библиотеки;
сделать плавное изменение размера и позиции карточек без рассинхронизации
кликабельных областей; проверить минимальный GUI-размер и длинные названия.

## Воспроизведение

Требуется Python 3 и Pillow. Изображения и шрифты берутся из ресурсов проекта.

```sh
python design/console-v2/render_preview.py --output build/design/console-v2
```

По умолчанию вывод идёт в игнорируемый `build/`, не в исходники.
Файлы: `main-menu-worlds-v2.png` и `main-menu-servers-v2.png`.
